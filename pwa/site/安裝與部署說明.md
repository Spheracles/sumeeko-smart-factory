# SUMEEKO Stage 4｜網站部署說明

本網站在 `index.html` 展示品牌及產品特色，在 `app.html` 提供互動智慧工廠功能。安裝 PWA 時 `manifest.webmanifest` 將 `app.html` 設為啟動頁面。

推薦將完整工程以 **GitHub Desktop** 發布到 GitHub。使用 `.github/workflows/deploy-pwa-pages.yml` 於 GitHub Actions 重新打包 TypeScript React，並將 `pwa/site` 部署到 GitHub Pages。

GitHub：**Settings → Pages → Build and deployment → Source → GitHub Actions**。於 **Actions** 查看部署結果。假設儲存庫叫 `sumeeko-smart-factory`，網址為 `https://你的帳號.github.io/sumeeko-smart-factory/`。

手機 Chrome 開啟 Pages HTTPS 網址 →「開始體驗」→ Chrome 選單「安裝應用程式」。完整驗收請測試九宮格、T1～T5、飛航模式重新啟動與學習紀錄保存。

本作品為非官方教育模擬，不代表實際工廠規格。
