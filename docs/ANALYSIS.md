# 原始 Artifact 功能分析與 Android App 設計

## 1. 原始 Artifact 功能分析

**來源**：https://claude.ai/artifact/1gEvW5ts4vPHFBzhUvfiXd（本專案的原始碼即為該 Artifact 的 React／TypeScript 原始碼，以及嵌入的《SUMEEKO：AI 工程師生存戰》）。

### 1.1 主題、目標使用者與用途

- **主題**：台灣汽車扣件與精密金屬零件製造（以世德工業公開背景為題材），職涯養成＋工廠經營＋工業工程＋智慧製造。
- **目標使用者**：製造業新人、IE／品質／生管學習者、AI 智慧製造人才培訓班學員。
- **核心用途**：透過可操作的模擬，理解製程、品質、排程、供應鏈、資料分析、AI 與 CIM，並體會系統最佳化的取捨。

### 1.2 既有功能、計算邏輯、互動流程與頁面

| 類別 | 內容 |
|---|---|
| 頁面 | 首頁、角色建立、工廠地圖、任務中心、任務流程（漫畫→簡報→小遊戲→決策→結果）、數據儀表板、AI 研發室、IE／CIM 中心、工程百科、職涯、設定、改善成果報告 |
| 章節 | 序章＋第一～十三章＋終局「鳳凰計畫」，共 15 個關卡 |
| 小遊戲 | 危險辨識、批號追溯、製程參數安全窗口、品質檢測（SVG 扣件）、班別人力配置、排程拼圖＋MRP、SPC／Cpk／柏拉圖／根因、供應鏈 TCO、資料清理＋瓶頸＋ROI、AI 專案×4、CIM 節點圖、數位孿生最佳化、AI 工程師生存戰（九關） |
| 計算邏輯 | `sim.ts` 工廠模擬引擎：各站可用工時、產能、瓶頸、FPY／RTY、OEE＝A×P×Q、Little's Law、12 類成本、CAPEX／OPEX、能源、PPM、OTIF、種子亂數；鳳凰計畫多目標評分與結局 |
| 職涯 | 10 個職位、技能樹 6 分支、認證、跨部門信任、升遷審查、進修、事件系統（14 種，3 選項，因果旗標） |
| 存檔 | localStorage 自動存檔、3 欄位、存檔代碼匯出入、版本遷移 |

### 1.3 原始視覺特色

深海軍藍底、金屬銀、橘黃強調、科技青；漫畫分鏡與對話框；2.5D 等角工廠地圖；原創 SVG 頭像與扣件；儀表板式 KPI 卡。

### 1.4 移植評估

| 可直接移植 | 需針對 Android 重構／新增 |
|---|---|
| 全部遊戲邏輯、模擬引擎、小遊戲、資料（純前端、無網路） | 底部五大導航（首頁／工作場景／圖鑑／任務／我的） |
| 存檔（WebView localStorage） | 系統返回鍵與手勢返回（網頁端返回堆疊） |
| 生存戰 iframe（同源 assets） | 安全區、背景暫停、觸控（拖曳替代、雙指縮放） |
| SVG 美術 | 3D 工件、機台狀態機、人物職業、教學單元、工站任務、圖鑑分類 |

### 1.5 不可修改或刪除的原始功能

原作職涯遊戲的全部章節、小遊戲、模擬公式、升遷規則、事件、存檔、百科與專利卡、生存戰串接。本 App 將其完整收納為「職涯模式」，未刪改任何功能；僅加入「返回 App」按鈕與返回鍵處理。

### 1.6 外部依賴

- 無外部 API、無帳號、無雲端資料、無真實 AI 模型（AI 功能皆為規則式教學模擬）。
- 原作網頁版載入 Google Fonts；**App 版已移除**，改用 Android 系統中文字型，可完全離線。
- 專利原文連結為外部網址，由系統瀏覽器開啟（需網路，非核心功能）。

## 2. Android App 架構

```
┌──────────── Android（Java） ────────────┐
│ MainActivity                             │
│  ├ WebView + WebViewAssetLoader          │  https://appassets.androidplatform.net/assets/www/
│  ├ onBackPressed → window.__handleBack() │  回傳 false 才 finish()
│  ├ onPause/onResume → __appPause/Resume  │  暫停動畫、音效、3D 繪製
│  ├ WindowInsets（API 35 edge-to-edge）    │
│  └ 外部連結 → 系統瀏覽器                   │
└──────────────────────────────────────────┘
┌──────────── Web 層（React 19 + TS） ─────┐
│ Shell（src/app/Shell.tsx）                │
│  ├ 啟動畫面 → 新手引導 → 底部導航          │
│  ├ 路由堆疊（machine/part/tool/unit/task…）│
│  ├ useBack 返回堆疊（Sheet > 頁面 > 分頁） │
│  ├ AppState（localStorage: sumeeko-app-v1）│
│  └ SoundEngine（WebAudio 合成）           │
│ machines.tsx：7 台 SVG 機台＋CSS 動畫       │
│ gl.ts：WebGL 渲染器＋程序化幾何            │
│ people.tsx：6 職業全身角色                 │
│ appdata.ts：設備／工具／材料／工件／教學／任務 │
│ 職涯模式：原作 App.tsx（完整保留）          │
│   └ survival.html（iframe，postMessage）   │
└──────────────────────────────────────────┘
```

資料保存（本機）：設定、教學完成狀態與答題、任務最佳分數／次數／最近 10 筆紀錄、收藏、最近觀看、上次位置、代表人物；職涯模式另存於原作的存檔鍵。

## 3. UI／UX 畫面設計

| 畫面 | 設計重點 |
|---|---|
| 啟動畫面 | 六角螺帽 Logo＋旋轉齒輪環、0.9 秒載入進度；Android 12+ 另有系統啟動畫面 |
| 新手引導 | 3 頁（歡迎、操作方式、安全聲明），可略過，可於「我的」重新顯示 |
| 首頁 | 主視覺＝2.5D 九宮格縮圖＋代表人物；繼續探索；4 格進度；推薦課程；下一任務；6 個快速入口；最近機台 |
| 工作場景 | 全畫面 SVG 場景；上方：場景名稱、目前任務、視角狀態、任務鈕；中央：人物、設備、熱點；下方工具列：縮放、總覽、標籤、操作提示；點擊開啟 Bottom Sheet（不遮住大部分場景） |
| 機台 | 狀態徽章（圖示＋中文＋英文＋顏色，不只靠顏色）、視角切換、SVG 機台＋編號熱點、進度條（顯示工序名稱）、控制面板（3 欄大按鈕，急停為紅色圓形）、參數（綠色安全窗口）、事件紀錄 |
| 3D 工件 | 畫布可拖曳／捏合；工具列：360°、剖面、半透明、放大、重置、材質；工序滑桿對照 |
| 教學 | ①～⑧ 卡片段落、前後 3D 對照、問答即時回饋、完成存檔 |
| 任務 | 六步驟膠囊進度；人物指引；結果卡（人物完成／警示動作） |
| 我的 | 成果、收藏、最近、設定（三種音量分開）、關於／授權／隱私、清除資料（需二次確認） |

觸控目標 ≥ 44 px；直式為主，橫式時場景與 3D 自動調整高度。

## 5. 人物與設備美術設定

### 5.1 人物

- 造型：深藍工作服＋橘色識別線條、織紋圖樣、中線車縫、識別證、安全鞋、護目鏡、耳罩、安全帽。
- 6 職業：製程工程師（平板）、機台操作員（作業紀錄）、模具技師（模具）、品質工程師（卡尺）、設備維護工程師（檢測儀器）、物流技術員（條碼掃描器），各自對應任務與工具。
- 視角：正面、3/4、側面、背面；動作：待機呼吸、指向設備、檢查工件、完成任務、異常反應。
- **目前為原創 SVG 2.5D 佔位美術**，尚未達到「擬真 ACG 立繪＋精細五官」的最終品質（見 TODO）。
- 安全：不呈現戴手套接觸運轉中旋轉部件、不呈現移除護罩。

### 5.2 設備

| ID | 設備 | 主要互動 |
|---|---|---|
| M01 | 多工位冷鍛成形機 | 送料、切料、逐站成形、轉送、出料；整機／內部（曲軸示意）／逐站 |
| M02 | 平板式搓牙機 | 固定與往復牙板、胚料滾動、推料、出料 |
| M03 | 軸向沖壓與二次加工機 | 滑塊沖壓、光柵、行程／壓力曲線（對應 TWI753649B 主題，參數虛構） |
| M04 | 網帶式連續熱處理爐 | 加熱區、淬火槽氣泡、回火區、溫度監測 |
| M05 | 表面處理線 | 吊掛輸送、各槽、乾燥固化（僅原理展示） |
| M06 | 自動光學檢測（AOI） | 振動盤、玻璃轉盤、相機與環形光、OK／NG 分流、統計面板 |
| M07 | 自動化組裝與物流 | 機械手臂、夾爪、輸送帶、AMR、條碼標籤、圍籬 |

規格書中的「M03 CNC 精密加工機」依原作主題（二次加工＝軸向沖壓、塗膠、套管組裝）調整為軸向沖壓機；CNC 列為後續可擴充項目。

## 6. 工件與工具

見 [ASSET-MANIFEST.md](ASSET-MANIFEST.md) 的 PART、TOOL、MAT 分類。工件依產品走不同途程：

- 六角螺栓：盤元 → 下料胚料 → 成形胚體 → 螺紋加工件 → 熱處理件 → 表面處理件 → 成品
- 預置扭力螺帽：盤元 → 下料胚料 → 冷鍛螺帽胚 → 攻牙後熱處理螺帽 → 軸向沖壓成品
- 組合式套管螺絲：…→ 表面處理件 → 套管組裝成品
