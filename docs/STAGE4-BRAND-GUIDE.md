# SUMEEKO 智慧工廠｜第四階段品牌識別與展示版

## 產品定位
獨立製作的非官方教育模擬作品，以互動機台、等角工廠與任務學習，介紹精密扣件製程。

## 品牌色彩
| 名稱 | HEX | 用途 |
|---|---|---|
| 深海藍 | `#0B1E33` | 背景 |
| 工業藍 | `#152F4D` | 面板 |
| 科技青 | `#00D4FF` | 操作與聚焦 |
| 活力橙 | `#FF9F2E` | 主要行動 |
| 鋼鐵灰 | `#7E8A99` | 機台材質 |

## 視覺素材
所有新圖像位於 `pwa/site/assets/`：
- `brand-guide.webp`：品牌識別看板（概念設計）
- `factory-cover.webp`：製程全景主視覺（概念設計）
- `home-concept.webp`：手機首頁（概念設計，非可互動截圖）
- `splash-concept.webp`：載入頁概念圖
- `logo-concept.webp`：Logo 概念圖
- `web-concept.webp`：GitHub Pages 展示站概念圖
- `icons/`：PWA 實際安裝圖示（192、512、maskable、Apple touch）

## 實際網頁（非圖片）
- `pwa/site/index.html`：可點擊的網站展示首頁
- `pwa/site/app.html`：操作版 React PWA
- `pwa/site/landing.css`：響應式展示站樣式
- `pwa/site/brand-app.css`：React App 品牌樣式增強
- `pwa/site/landing.js`：安裝說明及 SW 註冊

**重要區別：** 美術概念圖不是已實現的遊戲畫面。實際 App 繼承第三階段的 SVG、WebGL、CSS 改良，不是 UE5 3D 成品。
